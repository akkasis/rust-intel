# Известные ограничения

## Источники
* **BattleMetrics.com требует платную подписку.** Без неё API отвечает 403 (проверено 2026-11-08). Адаптер реализован и
  покрыт контрактными тестами на фикстурах, но **с реальным токеном не проверялся**. Пути endpoint'ов взяты из ранее
  опубликованной документации; страница документации недоступна автоматическому клиенту.
* **Steam не сообщает сервер.** Steam-трекер видит только «в Rust / не в Rust». Невидимый режим Steam и скрытые игровые
  данные выглядят как «не в Rust» — источник не позволяет отличить. Закрытый профиль → «неизвестно».
* **battlemetrics.ru — только серверный уровень.** История онлайна сервера не связана с конкретными игроками.
* **Баны проектов** не подключены: не найдено документированных публичных API. UI показывает «не подключено».
* **Боевая статистика (K/D, точность)** не поддерживается: ни один подключённый источник не даёт авторитетных полей.
* **Rust+** не интегрирован (P2, требует отдельной проверки условий).
* Steam Web API / battlemetrics.ru / Telegram **не проверены реальными запросами** в этой сессии — не было ключей. Статус в UI: «не проверен».

## Аналитика
* Сессии из опросов имеют точность ± интервал опроса; длительность показывается как «≥ N» (только точно наблюдённая часть).
* «Типичные игровые офлайн-часы» строятся только при ≥ 84 известных ячейках 7×24 и ≥ 3 разных днях наблюдения в ячейке.
  Это не утверждение о сне или распорядке человека.
* Связи и «возможные тиммейты» — гипотезы по совместным сессиям на одном сервере; требуют серверных сессий
  (на практике — BattleMetrics с подпиской или демо).

## Платформа
* Трекер работает, только пока приложение запущено (в т.ч. в трее). Спящий/выключенный ПК не наблюдает.
  Удалённый 24/7-мониторинг не входит в v1.
* **Установщик Windows не собирался локально** (разработка велась на macOS). Сборка NSIS и smoke-тест запуска
  настроены в GitHub Actions (`windows-latest`); результат зависит от первого прогона CI.
* Уведомления Windows, трей, автозапуск и Credential Manager проверены только компиляцией; функционально — в CI/на Windows.
* Если системное хранилище секретов недоступно, ключи держатся в памяти до закрытия приложения (UI предупреждает).
* Только русский язык интерфейса (строки локализуемы, но i18n-каталог не выделен).
* Подпись кода и канал автообновлений не настроены (P2) — SmartScreen может предупреждать при установке.
* `npm audit`: 10 moderate в dev-зависимостях ESLint (minimatch), не попадают в сборку приложения.
